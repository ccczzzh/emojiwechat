# 小猪咪｜角色视觉与微信表情包制作规范（STYLE GUIDE）

> **版本**：v1.0｜2026-11-19  
> **状态**：角色概念与后续制作基准；尚未产生正式投稿认证  
> **适用角色**：小猪咪（盘串喵的 CP）  
> **适用范围**：单人微信表情、吃货日常、双人 CP 表情、封面、图标、横幅及宣传图  
> **最高优先级规则**：**小猪咪不戴任何手串/珠串/文玩配件；所有创作以“爱吃好吃的”的粉色小猪为核心。**

## 0. 规范优先级

- **M｜必须**：不可改变的角色特征、禁止项、导出验收条件。
- **R｜推荐**：配色数值、比例范围、布局建议、选题示例；出现合理的视觉需求时可调整，但要保持批次一致。
- **P｜平台参数参考**：与微信投稿有关的尺寸及体积。**平台可能更新规则或因投稿类别不同而不同，提交时以当前页面的要求为准。**
- 与仓库根目录 [STYLE_GUIDE.md](../STYLE_GUIDE.md) 共享制作流程、字体和检查方法；但涉及 **盘串喵的手串、猫耳、无毛褶纹等角色专属条款不可套用到小猪咪**。

## 1. 角色身份和禁改特征（M）

| 特征 | 固定设计 | 不能出现 |
|---|---|---|
| 物种 | **小粉猪**，不是无毛猫、普通猫、狗或小熊 | 猫鼻、长三角猫耳、长毛猫尾巴 |
| 头部 | 圆润宽脸，脸部视觉重量大；略带婴儿肥 | 尖脸、长吻、写实猪头 |
| 耳朵 | **两只短而宽的软耳朵，向两侧下垂或外翻**；耳内浅粉 | 无毛猫的大直立三角耳 |
| 鼻子 | **突出、粉色椭圆/圆角猪鼻，两个明显的鼻孔** | 将猪鼻简化成猫式小三角鼻 |
| 眼睛 | 大眼、圆眼或开心弯眼；可有闪闪星星眼和傲娇半眯眼 | 每张眼睛形状无法对应角色情绪，或左右数量错误 |
| 腮红 | 两侧温柔的桃粉色腮红，笑时更明显 | 高饱和荧光粉大片覆盖脸颊 |
| 体型 | 头大身圆、短粗圆胳膊和腿、**圆滚小肚皮** | 细长人体四肢，过分写实肌肉 |
| 蹄子 | 四肢末端可采用**深棕/可可棕的圆蹄色块**，手持食物时以可辨的Q版握持爪形为主 | 多出手指、六条腿、穿模食物 |
| 尾巴 | **短小、向上卷曲的小猪尾巴**；正面全身图必要时露出一角 | 像猫一样又长又直的尾巴 |
| 皮肤 | 暖浅粉色身体、稍深粉色耳内/鼻头，柔和渐变 | 黑金、3D塑料质感、真实猪毛皮纹 |
| 轮廓 | **深巧克力棕色粗圆描边**，与盘串喵整套统一 | 细黑线、写实油画、霓虹描边 |
| 饰品 | **默认完全不戴饰品**。手串、珠链、项链、手镯、佛珠、文玩挂件均禁止 | 将早期“戴红棕串小猪”图作为标准形象 |

**视觉识别三要素：软耳朵＋椭圆双鼻孔猪鼻＋卷尾。** 即使手里没有食物，也应能一眼看出是小猪咪。

## 2. 性格、人设与 CP 关系（M）

**核心性格**：吃货、活泼、温暖、爱撒娇、容易开心；遇到食物会两眼放光，吃饱时会眯眼满足；偶尔护食、撒娇索要“最后一口”、嘴硬或被美食收买。

**主要动机**：对美食的期待、寻找、品尝、分享和享受；不是“每天必须抱汉堡”，也不是只会流口水的单一表情。

**与盘串喵的对照**：

- 盘串喵：粉色无毛猫、直立大耳朵、拽脸；热爱盘手串、核桃、文玩。
- 小猪咪：粉色小猪、软耳朵、猪鼻、卷尾；热爱好吃的，表情更加热情和外露。
- 两只角色可以形成“一个盘串、一个盘饭”的趣味反差；但**互动不能强行把小猪咪画成也盘串**。
- 双人互动优先选择：分零食、试吃、吃醋/护食、排队买小吃、投喂、一起打盹、一起庆祝。双方保持原本的个性，不需要每张都画成爱心/恋爱场面。

**命名**：项目名固定为「小猪咪」。其他昵称、性别、年龄、背景故事**暂未定稿**；不在设计文件中擅自锁定。

## 3. 角色比例、姿态和动作（R）

- 头部通常占角色整体可见高度约 **45%–60%**；和盘串喵站在一起时，小猪咪可略矮、略圆，但不强制固定身高关系。
- 软耳朵适度外张且明显成对，头与两耳整体宽度有Q版夸张感。
- 猪鼻处于脸的中心偏下位置，**两个鼻孔清晰分开**；嘴一般在猪鼻下方，张嘴吃东西时也不能吞掉猪鼻结构。
- 眼睛可变成：开心弯眼、惊喜亮眼、期待星星眼、护食眯眼、撑饱困眼；同一批次保持相似五官位置与线条风格。
- 圆肚皮是角色可爱要点，可轻轻捧腹/拍拍肚皮，但不要通过过度嘲讽体型制造笑点。
- 蹄色块在小型图上简化；捧食物时允许卡通手势，但左右手必须能数清。
- 尾巴在半身/近景可被构图遮挡，不需要为了显示尾巴而破坏手部动作。

## 4. 美食和道具（M）

### 4.1 食物是她/它的标志，不是饰品

- **默认道具为食物**，不是手串；从早餐、主食、小吃、甜品、饮品中选出与文案最贴切的一种。
- 第一批可使用：**汉堡、热包子、水饺、草莓蛋糕、奶茶、甜甜圈、火锅、炸鸡、冰淇淋、面条、烤串、蛋挞、水果、薯条、寿司、披萨**。
- 设计上建议**一张表情只有一个主食物**；例如吃包子时不同时堆满汉堡、蛋糕、披萨和奶茶。
- 只有明确场景要求时再加入餐盘、筷子、叉勺、吸管、外卖袋、围裙、餐巾或桌面；平时保持轻道具。
- **不能出现手串/项链/珠链，不能把文玩当成默认食物替代品。**
- 食物要能辨认，例如汉堡有面包/蔬菜/夹层，包子有褶皱，蛋糕有奶油/水果，奶茶有杯子/吸管；不要用含糊的黄色或棕色球代替一切食物。
- 食物与嘴、手的接触关系合理：不要穿过嘴巴、凭空悬浮；热气、香味、咀嚼线只使用少量。

### 4.2 防止动作重复

16 张至少覆盖 **6 种动作/情绪**，不能只换汉堡为包子，而所有画面都“坐着举食物、开心闭眼”。

| 情绪 | 画面动作参考 | 文案方向 |
|---|---|---|
| 期待 | 两眼放光地盯着蛋糕 | 「好想吃！」 |
| 喜悦 | 抱着汉堡笑出声 | 「开饭啦！」 |
| 陶醉 | 一口包子后两眼眯起 | 「太香了！」 |
| 满足 | 拍拍圆肚皮、长出一口气 | 「吃饱啦！」 |
| 护食 | 把点心护在怀里、斜眼看旁边 | 「不许抢！」 |
| 分享 | 将一半点心递向镜头 | 「给你一口」 |
| 等待 | 对着手机等外卖，肚子咕咕响 | 「外卖呢？」 |
| 后悔 | 吃撑后歪坐着 | 「撑到了」 |
| 诱惑 | 端着甜品邀请盘串喵 | 「来一口嘛」 |
| 困倦 | 吃完抱着空盘打盹 | 「饱困了」 |

> 此表是题材方向，**不代表已确定的正式16个文案**。

## 5. 颜色、轮廓及材质控制

以下是**推荐的内部色票（R）**，用于统一未来批次的视觉方向，并非对之前生成参考图的逐像素取样。

| 项目 | HEX 参考 | 作用 |
|---|---|---|
| 小猪主体皮肤 | `#F9CFCC` | 柔和暖粉，主体大面积 |
| 耳内、鼻头浅粉 | `#F5AFAB` | 与皮肤有层次差异 |
| 腮红 | `#F2A1A2` | 两颊短椭圆/短斜线 |
| 褶皱及阴影 | `#DE9189` | 少量肚皮、耳根等部位 |
| 轮廓与文字 | `#4B2419` | 深巧克力棕，与盘串喵统一 |
| 蹄子 | `#805348` | 温和可可棕，不抢脸 |
| 高亮黄色 | `#F7BE49` | 兴奋线条、星光、香味符号 |
| 汉堡/面包主色 | `#E9A247` | 仅食物使用，不能染黄小猪 |
| 草莓/爱心红 | `#EF787F` | 喜悦、甜品装饰 |
| 奶油白 | `#FFF3DC` | 包子、蛋糕和局部亮点 |
| 横幅背景参考 | `#F8EADB` | 不透明浅奶油色；与主图透明背景区分 |

- **描边**：最终240×240时，外轮廓推荐 3–5 px，五官 2–3 px，局部细节 1–2 px。
- **渲染**：2D 平涂、轻微柔和渐变、少量明暗；食物可以更鲜亮，但颜色不过饱和。
- **不允许**：黑金风、摄影写实、3D渲染、密集贴图、画面中嵌入透明棋盘格、不同张之间突然换描边颜色。

## 6. 文案与字体（M/R）

- **核心字体风格**：粗圆手写卡通中文字，深棕 `#4B2419`；数字化排版可使用**思源黑体 SC Heavy**作为底稿，再做适当圆角/手写化处理。需核对所用字体授权，不上传字体文件。
- **字号为内部设计建议，不是微信平台规定**：

| 文案长度 | 最终240px画布建议字号 | 处理 |
|---|---:|---|
| 2–3个汉字 | 36–46 px | 单行，醒目 |
| 4个汉字 | 32–40 px | 尽量单行 |
| 5–6个汉字 | 25–34 px | 必要时两行 |
| 7–8个汉字 | 20–27 px | 优先精简文案 |

- 文字通常放在上方 (Y≈8–65px) 或旁边，不挡猪鼻、眼睛、张嘴动作、食物主体。
- 一张图通常不超过两行；优先 2–6 个汉字，适量添加「！」、「～」、「？」。
- 文字笔画清晰，不得出现 AI 乱码、笔画缺损或错字；生成中文字不准确时，**先画无字版，后期用标准字体排版**。
- 文案情绪尽量从小猪咪自身视角表达，例如「饿了」「好香呀」「给你吃」「真好吃」，不要每张都照搬盘串喵的“盘”字梗。

## 7. 静态、动态图和专辑素材导出规范

**单位**：尺寸以 px 计；以下KiB大小按 1024字节计算，属于本项目内部交付目标，不保证等于微信开放平台每个投稿入口的官方上限。

| 素材 | 输出尺寸 | 编码 | 项目大小目标 | 背景/备注 |
|---|---|---|---|---|
| 静态表情主图 | **240×240** | PNG RGBA | **≤100 KiB**；优选≤80 KiB | **真透明背景** |
| 动态表情主图 | **240×240** | GIF | 尽量≤100 KiB | 透明、循环，帧数/时长按投稿入口 |
| 缩略图 | **120×120** | PNG RGBA | ≤50 KiB | 透明，与主表情同姿态 |
| 封面 | **240×240** | PNG RGBA | **≤80 KiB** | 透明底，突出小猪咪＋一种食物 |
| 面板图标 | **50×50** | PNG RGBA | **≤30 KiB**；优选≤15 KiB | 透明、无文字、脸部特写 |
| 横幅 | **750×400** | JPG或PNG RGB | 优选≤80 KiB | **不透明、柔和浅色；投稿版无文字** |
| 高清母版 | 建议**1024×1024** | PNG/分层文件 | 不限 | 尽量可编辑和保留透明 |
| 纯白展示版（可选） | **240×240** | PNG RGB | ≤100 KiB | **纯白 #FFFFFF 且完全不透明**，单独保存 |

### 7.1 背景规则

1. **表情、封面、图标默认透明**：真正的 Alpha 通道，画布边缘 Alpha=0，不把白底或黑底焊死在图片里。
2. **按需另做白底版**：背景统一 RGB #FFFFFF，完全不透明；不可与透明版本混放同一投稿目录。
3. **横幅不透明**：浅奶油色/浅桃色背景更适合展示，禁止黑金配色；微信投稿版不添加文字、二维码或水印。带标题版本只作 GitHub 或宣传预览。
4. 封面和图标不加满幅彩色方框；图标**必须重新做大头近景**，不可直接将多道具封面压到50×50。
5. 不得为了达到大小目标而把小猪五官压糊；不足以满足目标时保留质量并检查平台实际可用的大小上限。

### 7.2 安全区和可读性

- 240px画面重要内容距边缘至少 **8 px**，建议 10–14 px。
- 小猪鼻、两耳、嘴和主要食物应明显；主角不能过小，食物不能完全挡住猪鼻。
- 50px图标要能一眼识别猪鼻两个鼻孔和软耳朵，可保留一个小食物轮廓，但不能堆叠食物。
- 双人 CP 图需在240px尺寸下仍能区分盘串喵的猫耳与小猪咪的猪耳。

## 8. 动作生成的固定描述模板

> 一只名叫“小猪咪”的圆润可爱粉色Q版小猪，**不是猫**；短而宽、向两边自然下垂的软猪耳朵，粉色椭圆猪鼻上有两个清楚的鼻孔，柔和桃粉腮红，表情生动，身体圆滚滚、短圆四肢和小卷尾。与“盘串喵”同一套温暖可爱的二维手绘微信表情画风，厚实深巧克力棕色圆润轮廓、柔和暖粉色平涂。**不戴珠串、项链、手镯、佛珠，也不把文玩当默认道具**。本张核心是【指定情绪】＋【指定动作】＋【唯一主要食物】，用眼神、嘴和四肢清楚表达，画面简洁、主体完整、正方形构图，背景真正透明。中文文案后期另外排版，以确保准确无误。

**负面关键词**：

> no necklace, no bracelet, no wooden beads, no mala, no rosary, no jewelry, no Sphynx cat ears, no cat nose, no long straight tail, no furry body, no realistic pig, no 3D, no black-and-gold poster, no crowded restaurant, no extra limbs, no floating food, no gibberish Chinese, no fake checkerboard background.

### 8.1 每张表情制作说明卡

每次生成前至少写明：`编号｜文案｜唯一情绪｜主动作｜主食物｜近景/半身/全身｜文字位置｜输出类型（透明/纯白）`。

## 9. 与盘串喵双人表情的专属规则

1. **两个角色明显不同**：小猪咪软耳、猪鼻、卷尾；盘串喵超大三角耳、无毛猫褶纹和半眯眼。绝不互换鼻子、耳朵或尾巴。
2. **爱好不混淆**：小猪咪拿着食物，盘串喵在需要时盘文玩；两人可相互分享，但不把小猪咪设定为盘串爱好者。
3. **亲密关系的画面表达**：一起吃、互喂、靠在一起、举杯庆祝、亲亲等，基调温暖、俏皮；不要每张都必须画红心。
4. **配色与比例**：同一深棕描边，粉色皮肤略有层次，角色大小可以因剧情变化，但要保持一眼可识别。
5. **无食物的双人图**也可成立，但小猪咪不得因此被填上手串或猫耳。

## 10. 验收与发布检查清单（M）

### A. 角色一致性

- [ ] 是粉色小猪，不是猫；软耳朵、猪鼻双鼻孔、小卷尾形象稳定
- [ ] 脸部、肚皮、四肢和蹄子比例与本批其他图一致
- [ ] **身体、脖子、手腕均无任何文玩珠串或珠链**
- [ ] 食物类型和动作清楚，手脚数量正确，无穿模
- [ ] 角色、食物不被文字压住，中文无错字
- [ ] 画风与盘串喵同一套：深棕粗描边、暖粉平涂、少量黄闪光

### B. 工程质量

- [ ] 文件实际编码与扩展名一致，PNG/GIF能打开
- [ ] 尺寸精确匹配目标：240/120/50/750×400
- [ ] 大小满足本项目交付目标，或记录经平台核实的例外
- [ ] 透明版确实有Alpha、边角透明；白底版四角与整个背景确实是 #FFFFFF 不透明
- [ ] 轮廓无残留白边、黑边和棋盘格；小尺寸阅读清晰
- [ ] 编号无重复缺失，同名高清版/投稿版不混淆
- [ ] 动图循环正常，动作自然，无突然跳帧
- [ ] 作品不含第三方商标、二维码、水印或未授权素材

### C. 结果分级

- **A = 可以交付**：技术和视觉全部通过。
- **B = 需修整**：文字、边缘、局部形状或压缩可修复，复检后再交付。
- **C = 必须重做**：画成猫、突然带串、吃的食物不可辨、角色严重漂移、白底冒充透明、肢体严重出错。

全部单张达到 A，才标注为微信**技术预检通过**；技术预检不等于微信官方审核通过。

# 工位喵 · 第一批表情｜白色背景版

本目录收录 **16 张独立表情的纯白背景 PNG 版本**，包括最初转换的 13 张，以及后来补充的「搞定了」「救命啊」「带薪拉屎」3 张。

- **分辨率**：每张 240 × 240 像素；PNG，背景为纯白 `#FFFFFF`、完全不透明（不是透明底）。
- **文件大小**：每张低于 100 KiB；均保留原有猫咪、动作、文字和道具。
- **原图保护**：`工位喵/01_` 原始表情及 `横幅` 目录未被修改或覆盖。
- **用途提醒**：如果微信表情投稿入口要求透明背景，请选用原始透明 PNG，不要使用本白底版。
- **文件名说明**：保留各张图片原有名称；其中 `11_邮件999+` 与 `11_搞定了` 是不同图，`13_网络崩了` 与 `13_救命啊` 也是不同图。

# 盘串猫｜微信表情包项目记录

> 项目状态：角色方向已确定，正在制作单张表情素材。  
> 角色名称：**盘串猫**  
> 记录用途：统一角色设定、设计决策、已完成表情和后续制作规范，避免不同批次出现画风或造型漂移。

## 1. 项目定位

制作一套以「盘串猫」为主角的微信表情包。角色是一只粉色无毛猫，喜欢盘小叶紫檀手串，性格搞笑、略欠、带一点高冷。整体采用简洁、粗线条、表情夸张的漫画涂鸦风。

核心原则：

- 猫本身是画面主角，文玩道具只作点缀。
- 保持角色外形、头身比例、线条粗细和配色一致。
- 表情和动作要一眼能读懂，适合聊天场景。
- 不要为了表现“文玩”而堆叠过多饰品。
- 每张表情应独立清晰，避免多个动作挤在同一画面。

## 2. 已确认的角色设定（基准设定）

| 项目 | 已确认设定 |
|---|---|
| 名称 | 盘串猫 |
| 物种与外形 | 粉色无毛猫／斯芬克斯猫特征 |
| 头部 | 圆脑袋、大耳朵，保留明显的无毛猫辨识度 |
| 画风 | 简洁漫画涂鸦风，粗黑轮廓线，少量柔和阴影 |
| 表情 | 夸张、直接，常用半眯眼、斜眼、撇嘴等表现欠欠的高冷感 |
| 性格 | 搞笑、欠欠的、有点高冷；偶尔流露可爱和满足 |
| 标志道具 | 深红棕色小叶紫檀手串 |
| 主色调 | 粉色猫身、深棕/红棕色珠子、深色轮廓线 |
| 整体观感 | 简单、可爱、有脾气、有记忆点 |

### 角色一致性要求

1. 默认不改变粉色无毛猫、大耳朵、圆脑袋的基础造型。
2. 默认只使用一条简洁的小叶紫檀手串作为主要文玩标志。
3. 不随意增加项链、流苏、多层手串、挂件等复杂装饰。
4. 不改变原有粗黑线条和夸张漫画表情风格。
5. 设计新动作时优先调整姿势和表情，而不是增加配饰。

## 3. 第一批五个基础形象

最初规划的五个角色状态，用于建立角色视觉基准：

1. **得意盘串**：拿着手串，半眯眼，略带得意。
2. **不爽/生气**：抱臂或叉腰，皱眉、撇嘴。
3. **好奇张望**：探头，大眼睛，带问号。
4. **满足真香**：抱着手串，表情满足。
5. **盘串睡着**：趴着或抱着手串睡觉。

这些是基础形象方向，不代表已经完成五张符合微信上传规格的独立成品。

## 4. 设计迭代记录与决策

### 4.1 最初角色方案

- 采用粉色无毛猫。
- 以小叶紫檀手串作为主要道具。
- 画风从较柔和的涂鸦效果，调整为更简洁、线条更粗、表情更夸张的漫画风。
- 性格确定为搞笑、欠欠的、有点高冷。
- 角色名称确定为「盘串猫」。

### 4.2 文玩配饰尝试：核桃与多条手串

曾尝试增加以下元素：
- 脖子上挂一串珠子；
- 手里盘两颗核桃；
- 胳膊上再缠绕手串。

**最终决定：不采用这套复杂造型作为默认角色设计。**

原因：配饰过多，画面显得杂乱，削弱了原有角色的简洁感和辨识度。

后续如需出现核桃，可以将核桃作为单张表情中的临时道具，不要同时堆叠项链、流苏和多圈手串。

### 4.3 当前统一设计原则

回归最初的盘串猫：
- 保留原有粉色无毛猫造型；
- 保留粗黑漫画线条和夸张表情；
- 小叶紫檀手串作为主要标志；
- 文玩只是点缀，不能盖过猫本身；
- 新表情优先通过动作、表情和少量符号表达。

## 5. 已设计的表情：「冲牙！」

### 表情名称

**冲牙！**

### 动作要求

- 一只手叉腰；
- 另一只手向前举起，手中拿着一串兽牙串；
- 身体和手臂姿势要有向前展示、挑衅或炫耀的感觉；
- 表情采用盘串猫标志性的半眯眼、略带不屑的神态；
- 整体保持漫画式夸张和幽默感。

### 道具要求

- 兽牙串是这张表情的重点道具；
- 兽牙应呈浅象牙色、串成一圈或一串，视觉上清楚可辨；
- 不要因此增加复杂项链、流苏或额外多层配饰；
- 角色原有小叶紫檀手串可以保留为简洁配饰，但不能抢过兽牙串的视觉重点。

### 画面要求

- 角色完整、动作清晰；
- 手叉腰的动作必须明确；
- 向前举起的手和兽牙串不能被身体遮挡；
- 如加入文字，文字为「冲牙！」，位置不要遮挡猫脸和兽牙串；
- 保持与基准角色相同的粗黑轮廓和粉色配色。

> 当前已生成「冲牙！」概念图。概念图不等于最终上传素材；后续仍需单独导出、检查透明背景、尺寸、文件大小和边缘质量。

## 7. 单张表情制作规范

### 视觉规范

- 每张只表达一个主要情绪或动作。
- 角色外观必须与基准设定一致。
- 粗黑轮廓线，简洁漫画涂鸦风。
- 控制配饰数量，避免画面杂乱。
- 中文文案尽量短，避免复杂字体和过多装饰。
- 角色、道具、文字之间留出空间，缩小后仍能辨认。

### 资产规范

建议每张表情单独保存，不要只保留拼图或整套预览图。

建议目录结构：

```text
盘串猫/
├── README.md                 # 本项目设定与进度记录
├── references/               # 角色参考图、风格参考图
├── concepts/                 # 概念图、草稿、拼图预览
├── source/                   # 单张表情的原始高清文件
├── stickers/                 # 处理后的单张表情成品
├── thumbnails/               # 缩略图
├── cover/                    # 专辑封面、详情横幅等
└── checks/                   # 尺寸、格式、文件大小检查记录
```

### 微信平台规格

正式制作和上传时，以微信表情开放平台当时显示的最新官方规范为准。不要仅凭旧教程假定图片尺寸、文件大小、张数或审核规则仍然有效。

每次导出至少检查：
- 图片尺寸和格式；
- 文件大小；
- 背景透明度及边缘是否有白边；
- 文字是否清楚、有无错字；
- 缩小显示时角色和道具是否仍清晰；
- 整套表情的角色造型是否一致。

## 9. 后续协作约定

后续继续制作盘串猫时，默认遵循本文件中的基准设定。除非明确提出修改角色设定，否则不要擅自改变猫的外形、画风、主色调或配饰复杂度。

每新增一张表情，记录：
1. 表情名称和文案；
2. 姿势与情绪；
3. 道具及其摆放；
4. 是否符合角色基准；
5. 概念图与最终素材状态；
6. 导出规格检查结果。

**最重要的判断标准：一眼看上去必须还是同一只盘串猫。**

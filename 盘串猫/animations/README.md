## 动画验收重点

- 角色中心轴和尺寸保持稳定；
- 不出现无意的上下左右漂移、抖动或旋转；
- 探头动作由遮挡/显露变化表现；
- 问号可以单独做弹出回弹，猫咪本体保持静止；
- 循环首尾衔接自然。

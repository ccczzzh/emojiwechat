# 基础表情包需求清单（V1）

## 背景

为了满足日常聊天、社群互动及评论区表达需求，需要优先推出一批高频基础表情包。

设计风格可参考 iPhone Emoji、微信表情及主流社交软件常用表情，以简洁、易识别、高复用率为目标。

# 设计原则

1. 优先覆盖用户 80% 以上的日常表达需求。
2. 单个表情在小尺寸（48×48、64×64）下依然易于识别。
3. 风格统一，避免过于复杂的细节。
4. 支持后期扩展为动态表情（GIF/Lottie）。
5. 尽量避免文字依赖，提高跨语言适配能力。
6. 表情情绪幅度要明显，保证在聊天流中一眼识别。

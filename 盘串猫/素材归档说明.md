# 盘串猫｜图片与动图素材归档

本目录用于分别管理静态图片和动态表情。**本次先建立归档目录与清单；此前生成的图片/GIF二进制文件尚未写入仓库**，因为当前会话没有可供 GitHub 上传的原始文件路径或文件字节。不要把本清单误认为素材文件已经上传。

## 静态图片

见 [concepts/](concepts/README.md)。当前讨论过的静态素材包括：
- 「冲牙！」五款动作合集概念图；
- 单独的「问号」盘串猫概念图；
- 其他盘串猫角色/表情概念图（如有独立原图，待归档）。

## 动图

见 [animations/](animations/README.md)。当前讨论过的动图包括：
- 「探头后弹出问号」动画：早期预览；
- 40帧版本：曾提出角色动作连续性优化；
- 20帧版本：要求角色本体固定在画面中心轴，不上下左右晃动，只通过逐步显露表现探头，问号单独弹出。

注意：最后提出的20帧版本因图片生成额度限制，**尚未生成**；不能作为已完成素材归档。

## 最终表情成品

见 [stickers/](stickers/README.md)。概念图与正式微信表情成品分开保存。正式成品需单独检查透明背景、尺寸、格式、文件大小和边缘质量。

## 文件命名建议

- 静态图：`问号_概念图_v01.png`、`冲牙_五款合集_v01.png`
- 动图：`探头问号_预览_v01.gif`、`探头问号_40帧_v01.gif`、`探头问号_20帧_固定角色_v01.gif`
- 成品：`问号_sticker.png`、`探头问号_sticker.gif`

只有实际文件完成上传后，才将对应条目标记为“已归档”。
